# Miyakodo

Este repositório produz o conteúdo da Miyakodo.

A Miyakodo é uma escola de inteligência artificial para empreendedores. Pedro Miyasaki é o CEO, o fundador e o único professor. A voz pública é a dele, em primeira pessoa, porque ele é quem ensina. A escola não é uma marca pessoal.

O conteúdo é publicado no perfil Pedro Miyasaki, no handle `@pedro.miyasaki.ia`. Isso é founder-led growth: publicar no perfil do fundador para a escola crescer. O perfil é o canal. A instituição é a escola.

No longo prazo, a escola caminha para uma comunidade, algo mais complexo. O desenho dessa comunidade não está definido neste repositório.

As instruções de operação para agentes estão em [AGENTS.md](AGENTS.md).
