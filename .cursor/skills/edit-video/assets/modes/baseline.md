# Modo · baseline

Edição mínima: adensa a fala e normaliza o áudio. Sem overlays. Legendas do
vídeo queimadas como em todo modo, só no render final
(`assets/features/subtitles.md`).

## Features (ordem)

1. `cut-dead-air` → `assets/features/cut-dead-air.md`
2. `loudnorm` → `assets/features/loudnorm.md`

## Quando usar
Tese / posicionamento, ou qualquer vídeo sem um beat de notícia concreto. O
padrão quando o usuário não pede modo e a transcrição não cita nada novo.
