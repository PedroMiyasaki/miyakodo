# Mode · baseline

Minimal edit: densifies the speech and normalizes the audio. No overlays.
Burned-in subtitles like every mode, at the final render only
(`assets/features/subtitles.md`).

## Features (order)

1. `cut-dead-air` → `assets/features/cut-dead-air.md`
2. `loudnorm` → `assets/features/loudnorm.md`

## When to use it
Thesis / positioning, or any video with no concrete news beat. The default when
the user does not ask for a mode and the transcript cites nothing new.
